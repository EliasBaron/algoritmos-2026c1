
# CSES Problem Set: String Matching

Dado un string y un patrón, tu tarea es contar la cantidad de posiciones donde el patrón ocurre en el string.

## Input
La primera línea de la entrada contiene un string de longitud $n$, y la segunda línea contiene un patrón de longitud $m$. Ambos consisten únicamente de caracteres de la 'a' a la 'z'.

## Output
Imprime un entero: la cantidad de ocurrencias del patrón en el string.

## Constraints

$1 \leq n, m \leq 10^6$

---

### Ejemplo

**Input:**
```
saippuakauppias
pp
```

**Output:**
```
2
```
